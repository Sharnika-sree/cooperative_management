# ESP32 IoT Sensor Integration Contract & Hardware Specification

**Document Version:** 1.0.0  
**Target Architecture:** ESP32 Microcontroller + RS485 Modbus / Analog Soil Sensor + Smart Coop Node.js API  
**Status:** Hardware-Ready Integration Contract (Physical device pending)  

---

## 1. Overview & Architectural Scope

This specification defines the communication and data contract between future physical ESP32 sensor hardware nodes deployed in agricultural fields/greenhouses and the Smart Cooperative Society Management System backend.

The backend accepts real-time sensor measurements over HTTP/HTTPS, validates operational ranges, tracks reading freshness, prevents uncalibrated values from polluting ML model predictions, and prepares telemetry for the existing CatBoost Soil Suitability inference engine without requiring any retraining or architectural rebuilding.

> **CRITICAL NETWORKING REQUIREMENT:**  
> The ESP32 is an independent embedded system running on its own Wi-Fi / cellular stack.  
> It **must NEVER connect to `http://localhost:5000` or `http://127.0.0.1:5000`**, because `localhost` on the microcontroller refers to the microcontroller itself.  
> The ESP32 firmware must be configured with the backend server's **reachable LAN IPv4 address** (e.g., `http://192.168.1.100:5000/api/sensors/readings`) or the **production HTTPS endpoint** (e.g., `https://coop.example.com/api/sensors/readings`).

---

## 2. Ingestion Endpoint & Transport Details

- **Protocol:** HTTP/1.1 or HTTPS  
- **Method:** `POST`  
- **Endpoint URL:** `/api/sensors/readings`  
- **Content-Type:** `application/json`  
- **Timeout Recommended:** 5000 ms (ESP32 HTTP client)

---

## 3. Device Identification & Authentication

The ESP32 authenticates itself via a pre-shared device secret key stored securely in the ESP32 firmware's non-volatile storage (NVS) or configuration flash.

### Supported Authentication Headers (either is accepted):
1. **Custom Header:**
   ```http
   x-sensor-api-key: smartcoop_sensor_secret_key_2026
   ```
2. **Standard Bearer Header:**
   ```http
   Authorization: Bearer smartcoop_sensor_secret_key_2026
   ```

*Security Rules:*
- Device keys are managed via server environment variables (`SENSOR_API_KEY`).
- Sensor secret keys must **never** be exposed in frontend React client code.
- Unauthenticated requests are rejected immediately with HTTP 401 Unauthorized.

## 4. Ingestion Payload Schema (JSON)

### Specification Table

| Field | Type | Required | Units / Format | Allowed Operational Range | Description |
| :--- | :--- | :---: | :--- | :--- | :--- |
| `deviceId` | String | **Yes** | Alphanumeric (e.g. `"SOIL-DEVICE-001"`) | 3 to 64 chars | Unique identifier for physical sensor unit |
| `temperature` | Float | **Yes** | Celsius (°C) | `-10.0` to `65.0` °C | Ambient or probe soil temperature |
| `humidity` | Float | **Yes** | Percent (%) | `0.0` to `100.0` % | Relative air humidity |
| `moisture` | Float | **Yes** | Volumetric Percent (%) | `0.0` to `100.0` % | Soil volumetric water content / moisture |
| `timestamp` | String | **Yes** | ISO-8601 UTC String | Valid date, `now - 24h` to `now + 60s` | Timestamp generated by ESP32 (via NTP) |
| `nRaw` | Float / Null | Optional | Raw units / ADC / ppm | `0.0` to `5000.0` or `null` | Raw Nitrogen sensor telemetry |
| `pRaw` | Float / Null | Optional | Raw units / ADC / ppm | `0.0` to `5000.0` or `null` | Raw Phosphorus sensor telemetry |
| `kRaw` | Float / Null | Optional | Raw units / ADC / ppm | `0.0` to `5000.0` or `null` | Raw Potassium sensor telemetry |
| `unitMetadata` | Object | Optional | Key-value pairs | Arbitrary JSON object | Sensor probe model, firmware version, battery mV |

### Example Request Payload

```json
{
  "deviceId": "soil-device-001",
  "temperature": 28.5,
  "humidity": 68.0,
  "moisture": 42.0,
  "nRaw": 145.2,
  "pRaw": 38.6,
  "kRaw": 210.0,
  "unitMetadata": {
    "probeModel": "RS485-NPK-7IN1",
    "firmwareVersion": "v1.2.0",
    "batteryMilliVolts": 3850
  },
  "timestamp": "2026-10-17T06:30:00.000Z"
}
```

## 5. Backend Validation & Acceptance Rules

The backend strictly enforces the following validation checks:
1. **Header Check:** Confirms `x-sensor-api-key` matches `SENSOR_API_KEY`.
2. **Type & Finite Checks:** `temperature`, `humidity`, and `moisture` must be finite numbers; `NaN` and `Infinity` are rejected with HTTP 400.
3. **Range Checks:**
   - Temperature must be between -10.0°C and 65.0°C.
   - Humidity must be between 0.0% and 100.0%.
   - Moisture must be between 0.0% and 100.0%.
4. **Timestamp Verification:** Must be a valid parseable ISO-8601 string. Future timestamps greater than 60 seconds ahead are rejected.
5. **Raw NPK Isolation:** `nRaw`, `pRaw`, and `kRaw` are stored as raw sensor values. They are **never** assumed to equal CatBoost `N_score`, `P_score`, or `K_score`.

### Unauthorized Error (HTTP 401 Unauthorized)
```json
{
  "error": "Unauthorized",
  "message": "Invalid or missing sensor device API key. Provide header \"x-sensor-api-key\" or \"Authorization: Bearer <KEY>\"."
```

```json
{
  "error": "Validation Error",
  "message": "Humidity reading must be between 0% and 100%."
}
```

## 7. Status & Query Endpoints for Frontend

1. **`GET /api/sensors/status?deviceId=SOIL-DEVICE-001`**
   - Returns genuine connection status.
   - If no reading exists or the latest reading is older than `SENSOR_FRESHNESS_LIMIT_MS` (default 15 minutes / 900,000 ms), returns:
     ```json
     {
       "connected": false,
       "status": "Not Connected",
       "message": "No sensor device is connected. Connect an ESP32 device to receive live readings."
     }
     ```
   - When active and fresh:
     ```json
     {
       "connected": true,
       "status": "Connected",
       "message": "Sensor device is online and transmitting live telemetry.",
       "deviceId": "SOIL-DEVICE-001",
       "latestReadingTime": "2026-10-17T06:30:00.000Z",
       "isFresh": true
     }
     ```

2. **`GET /api/sensors/latest?deviceId=SOIL-DEVICE-001`**
   - Returns the most recent reading object and freshness metadata.

## 8. ESP32 Arduino / C++ Reference Implementation Template

*(For future implementation when physical ESP32 and RS485/NPK sensors are procured)*

```cpp
#include <WiFi.h>
#include <HTTPClient.h>
#include <time.h>

const char* WIFI_SSID = "Coop_Agricultural_WiFi";
const char* WIFI_PASSWORD = "secret_wifi_password";

// IMPORTANT: Use server LAN IP address or production HTTPS URL, NEVER localhost!
const char* SERVER_URL = "http://192.168.1.150:5000/api/sensors/readings";
const char* SENSOR_API_KEY = "smartcoop_sensor_secret_key_2026";
const char* DEVICE_ID = "SOIL-DEVICE-001";

// NTP time configuration
const char* NTP_SERVER = "pool.ntp.org";
const long GMT_OFFSET_SEC = 19800; // IST (+5:30)
const int DAYLIGHT_OFFSET_SEC = 0;

void setup() {
  Serial.begin(115200);
  WiFi.begin(WIFI_SSID, WIFI_PASSWORD);
  while (WiFi.status() != WL_CONNECTED) {
    delay(500);
    Serial.print(".");
  }
  Serial.println("\nWiFi connected.");
  configTime(GMT_OFFSET_SEC, DAYLIGHT_OFFSET_SEC, NTP_SERVER);
}

void loop() {
  if (WiFi.status() == WL_CONNECTED) {
    HTTPClient http;
    http.begin(SERVER_URL);
    http.addHeader("Content-Type", "application/json");
    http.addHeader("x-sensor-api-key", SENSOR_API_KEY);

    // Read physical sensors (e.g. RS485 Modbus soil sensor / SHT30)
    float temperature = 29.4; // Replace with sensor read call
    float humidity = 65.2;    // Replace with sensor read call
    float moisture = 44.0;    // Replace with sensor read call

    // Format ISO-8601 timestamp from NTP
    struct tm timeinfo;
    char timestampStr[32];
    if (getLocalTime(&timeinfo)) {
      strftime(timestampStr, sizeof(timestampStr), "%Y-%m-%dT%H:%M:%SZ", &timeinfo);
    } else {
      strcpy(timestampStr, "2026-10-17T06:30:00Z");
    }

    // Construct JSON payload
    String payload = "{";
    payload += "\"deviceId\":\"" + String(DEVICE_ID) + "\",";
    payload += "\"temperature\":" + String(temperature, 1) + ",";
    payload += "\"humidity\":" + String(humidity, 1) + ",";
    payload += "\"moisture\":" + String(moisture, 1) + ",";
    payload += "\"nRaw\":null,";
    payload += "\"pRaw\":null,";
    payload += "\"kRaw\":null,";
    payload += "\"timestamp\":\"" + String(timestampStr) + "\"";
    payload += "}";

    int httpCode = http.POST(payload);
    Serial.printf("HTTP Response code: %d\n", httpCode);
    http.end();
  }

  // Sample every 5 minutes (300,000 ms)
  delay(300000);
}
```
